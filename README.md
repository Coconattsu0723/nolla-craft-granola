# nolla CRAFT GRANOLA

## 概要

「nolla CRAFT GRANOLA」は、30代前半の働く女性を中心ユーザーに想定した、ポートフォリオ用の架空商品LPです。朝の気分に合わせて3つの味から選べる、7日間の買い切りグラノーラセットを1ページで紹介しています。

実際の商品販売・注文・決済は行いません。

## 制作目的

- 朝の悩みへの共感から商品理解・購入検討へつなげるLP設計
- 商品のある暮らしを写真とスクロール体験で伝えること
- 診断、カルーセル、画像切り替えを外部ライブラリなしで実装すること
- SPを基準に、タブレット・PCへ展開するレスポンシブ対応

## 使用技術

- HTML
- CSS
- JavaScript

## 主な機能

- 3問のフレーバー診断と結果表示
- 追加フレーバーの変更
- `sessionStorage`による診断・選択状態の保持
- INSIDE THE BOWLの段階画像切り替え
- THREE FLAVORSカルーセル
- SEVEN MORNINGSの7日間ストーリー
- SP用固定ハンバーガーメニュー
- 表示位置に応じて状態が変わる固定CTA
- `details` / `summary`を使った商品詳細とFAQ
- `dialog`を使ったポートフォリオ案内
- モバイルファーストのレスポンシブ対応
- `prefers-reduced-motion`への対応

## 公開方法

- `nolla_lp_project`全体をGitで履歴管理する方針です。
- GitHubへpushし、GitHub Pagesの`main / docs`を公開元として使用します。
- 公開用ファイルは`docs/`にまとめ、制作元のHTML・CSS・JavaScript・画像は移動しません。
- 公開URLは未設定です。

## デザイン方針

「Soft Morning」を軸に、自然光の写真、オフホワイトと淡いベージュ、フレーバーカラーを使用しています。余白を大切にし、上質さと親しみやすさの両立を目指しました。強いセール表現や過剰なアニメーションは避けています。

## 制作上の工夫

- SP版を正本とするモバイルファースト設計
- FAQやメニューにHTML標準の`details` / `summary`を使用
- 追加フレーバーを共通状態で管理し、診断結果・商品画像・内訳・Final CTA・ダイアログを同期
- CSS Scroll SnapでカルーセルとSPの段階表示を実装
- Intersection Observerでボウル画像と固定CTAの状態を制御
- `dialog`要素の標準機能を利用し、閉じた後のフォーカスを元のCTAへ戻す
- CSS変数で配色、余白、角丸、重なり順を一元管理
- `prefers-reduced-motion`で動きを抑えた表示を用意

## 注意事項

- 本サイトはポートフォリオ制作のために作成した架空サイトです。
- 実際の商品販売・注文・決済は行いません。
- 口コミはポートフォリオ用のサンプルコメントです。
- 商品情報、価格、送料、原材料、アレルギー表示は架空の設定です。
